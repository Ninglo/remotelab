# 副屏使用说明

副屏让你在工作时看一眼自己的任务状态、提醒或选定画面。详细信息和实际操作仍回到 RemoteLab 或原业务页面。它显示最近收到的状态，不能凭一个图标判断任务已经验收、消息已经读过或设备已执行成功。

## 开始使用

在 RemoteLab 的“设置 → 副屏”查看自己的设备。首次配对需要把副屏连接到支持的 Mac；把下面这段交给负责设备的 Agent：

> 请连接我的副屏。先核对我的登录身份、设备型号、USB连接和已有配对，沿当前实例的副屏安装入口完成设置。保留原布局与提醒设置，验证设备收到画面后告诉我应观察什么。

当前仓库的 USB 适配器支持 macOS 和 Thermalright 0416:5408。其他设备能否使用需要另核适配。安装链接十分钟内有效、只能使用一次；失效时从自己的设置页重新生成，不借用其他人的配对链接。

## 日常操作

| 想做什么 | 从哪里操作 | 会发生什么 |
| --- | --- | --- |
| 看任务状态 | 已配对副屏的状态画面 | 展示自己身份关联的任务概况，具体结果回原会话看 |
| 改布局或主题 | 设置里的详细编辑器 | 先预览，再应用到自己的副屏；仅预览不会改变设备 |
| 放GIF或一句话 | 设置里的简易内容编辑器 | 保存后切到个人内容；可恢复状态画面 |
| 返回任务状态 | “恢复状态屏” | 停止详细布局的预览流或个人内容，回到当前配置的状态视图 |
| 查看是否应用成功 | 编辑器的状态与回执 | 分别看提交、设备下载与USB写入；实体外观仍需现场看一眼 |
| 不再使用某块设备 | 自己的设备列表 | 断开配对，之后需重新配对才能继续接收画面 |

已应用的布局持续保留，不会每天到期。同一人名下的设备当前共用个人内容；换账号后要重新核对设备归属。详细编辑器和简易GIF编辑器是两种入口，保存简易内容或恢复状态屏会让详细预览让位。

## 状态和提醒是什么意思

| 看到的状态 | 应怎样理解 |
| --- | --- |
| 执行中 | 任务正在执行，结果尚待检查 |
| 排队 | 请求已接受，等待开始；没有排队时详细布局可能隐藏此栏 |
| 等待 | 会话进入等待状态，请回原会话看具体原因，不自动等于紧急事项 |
| 有结果可看 | 提醒你浏览已有结果，不代表结果已验收，也不保证需要你行动 |
| 待确认／异常 | 先看来源及是否“待核对”，再回原任务处理 |
| 即将到期 | 来自已配置的提醒及时间信息，具体安排以原日历为准 |
| 状态未更新／不可用 | 数据过期或读取失败，不能解释为零任务、零消息或没有日程 |

不同布局展示的状态不完全相同。飞书消息和日历提醒依赖已接入的身份、权限、订阅及事件范围，不覆盖整个个人收件箱。普通画面刷新只读取缓存，不会每次查询飞书；声音是否启用也取决于当前布局与本机设置。

## 画面不对时

| 问题 | 先做什么 | 交给Agent核查什么 |
| --- | --- | --- |
| 黑屏或画面不变 | 检查USB供电、数据线和Mac连接 | 设备是否在线、本机代理是否运行、最近下载与USB回执 |
| 网页预览变了，实体没变 | 核对是否点了应用、登录账号是否正确 | 当前帧ID、设备下载和USB确认；不要重复配对覆盖原配置 |
| 显示旧任务或旧提醒 | 看“状态未更新”等提示，回原会话核对 | 来源时间、服务连通性、当前身份及有效期 |
| 消息已读但提醒没消失 | 回飞书确认实际状态 | 事件覆盖和授权；必要时对当前人做一次明确刷新 |
| 读取失败或额度不足 | 保留错误与发生时间 | 权限、订阅、账号额度；额度耗尽不能靠连续重试恢复 |
| GIF不动或较慢 | 核对文件限制和当前画面模式 | 文件最多3MB、48帧、30秒，每帧不超过307200像素；设备为采样播放，不保证原GIF帧率 |
| 编辑器提示登录或找不到设备 | 从当前实例重新登录，再看自己的设备列表 | 身份绑定及配对，不使用其他人的设备凭据 |

可以直接说：“我的副屏在这个时间出现这个问题，网页预览是这样，实体屏是这样，请保留配对与设置排查。”涉及短暂动作时需要现场配合观察；网络或USB回执不能代替人的外观确认。
