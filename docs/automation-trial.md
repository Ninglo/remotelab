# 独立自动化试用

可以交给 Agent 的请求：

> 请在自动化试用入口创建【任务目的】，输入是【材料】，输出【要求】，交给【本页或指定 Agent 会话】，在【日期／周期】执行。沿现有 SOP 操作，说明预计成本；除非我另有要求，不增加预算限制。保留负责人、生效范围和监管预警说明。不要迁移已有自动化。

入口通过现有 preview 代理发布，例如 `/preview/automation-trial/`，使用该试用服务的独立登录。服务绑定 loopback，由 systemd／launchd 管理；主服务无需重启。它只管理独立目录 `automation-trial` 中的新任务，不读取或改写旧 Schedule、Trigger、监控恢复台账；没有周度任务。首次进入为空，填写任务或点击“填入试用示例”后创建。“我点运行时”不会自动执行；“运行一次”才提交真实 Agent 工作。指定时间和 cron 使用服务器监管器触发，日期输入按浏览器本地时区，cron 按所填时区。

任务定义包含目的、输入、输出、接收方、预计成本、负责人、生效范围、生效日期、监管与预警，以及执行 SOP。预计成本是说明文字，不生成预算、限额或费用暂停规则；默认没有成本样本，示例中的时间是粗略估计。可从执行会话查看实际模型用量。编辑产生新定义版本，在途运行保留当轮快照。

正常工作由原生 Session/Run 执行。一个独立观察器每两秒只检查试用任务，重启后继续观察已登记的原运行。启动请求不确定时使用原 requestId 核对，追加两次启动尝试后提示具体执行通路问题；不把启动失败称作 Agent 已修复。执行报错或没有有效结果时进入最多两轮 Agent 诊断修复；收到明确人工依赖时直接显示所需动作。缺口保留在原轮次，下次周期不会覆盖。人为补充通过“补充并继续”接续原问题。

监管通路暂不可读时，在任务上显示读取失败并保留原运行；恢复后接着观察，不因此启动第二份执行。业务预警说明传入执行 SOP，由 Agent 按具体任务处理。

完成依据是 Agent 按任务 SOP 核验后交接的结果，包含正文、实际来源和具体人工依赖。运行退出成功但没有有效结果不能完成。通用观察器不对所有业务重复实施另一套内容审核。可选的“无执行事件预警”检查运行事件时间，表示缺少活动信号，不能宣称业务进展停滞；它会提示人查看仍在运行的会话，不杀掉运行或启动第二份工作。

当前可操作交付方式：

- **给我 · 本页与任务会话**：结果和人工预警写入本页以及执行会话。页面明确显示该渠道，不表示已经发出飞书消息，也不要求人额外点击“确认接手”。此版本尚未接飞书通知。
- **交给指定 Agent**：通过原生消息接纳接口，将结果交给选定会话；界面说明已接纳，后续处理见该会话，不称对方工作已经完成。人工依赖仍显示在原任务页和执行会话。

通知失败保留已有结果，点击“重发通知”只重试交付。暂停只停止后续触发，在途运行继续；结束日期也停止新轮次，在途结果仍会接收。需要停止在途 Agent 可打开执行会话使用原停止功能。

实现：`automation/trial/{model,store,engine,runtime,service,routes,server}.mjs`，页面 `static/automation-trial/`。服务 API 为 `/api/automation-trial`（读取与创建）和 `/api/automation-trial/action`（run、pause、resume、continue、deliver、edit）。预览代理只开放这两个精确 POST 路径。服务用本实例原生 HTTP 客户端调用已有执行接口，不启动第二个聊天控制面。机器状态在实例配置目录，源代码不包含业务数据。

验证：`node scripts/run-with-clean-instance-env.mjs node --test tests/test-automation-trial.mjs`。测试的 runtime adapter 是隔离夹具，覆盖失败转修复、人工依赖、重启接续、交付失败不重跑、新周期不抹掉旧问题、到期和暂停。页面及真实模型执行另在试用目录核验，不能用夹具通过代替真实运行成功。

部署由 Agent 完成：将独立访问凭据的 SHA-256、监听端口和本次试用归属放入实例私有配置，设置 `REMOTELAB_TRIAL_CONFIG` 与 `REMOTELAB_TRIAL_SOURCE_SESSION`，启动 `automation/trial/server.mjs`；使用现有 `preview expose` 注册稳定入口及两个 POST 路径。凭据、任务材料和运行结果不提交 Git。停止试用服务并撤销该 preview 路由即可关闭入口，不取消已经接纳的原生运行；在途运行沿原会话操作。
