# Amber 主题的用量显示

2026-10-03 起，任何已登录用户选择 Amber 都会看到这两项用量。切换到其他主题时，界面和请求都不显示或读取它们。用户选用 Amber 即是显示开关；不另设 Person 白名单。

- 宠物旁：当前 RemoteLab **实例**所用 Codex 账号的剩余额度。默认显示每周窗口，点击查看其他窗口、重置时间与采样时间。只读取 Codex 额度，接口中的模型备用额度不作为这项百分比。百分比仅在账号版本匹配且采样足够新时展示；否则显示「暂不可用」。这不是每位用户独享的额度。
- 会话标题右侧：账本记录的该 Session 累计 Token，单位 `k`，悬停可看精确值。含该 Session 的后台调用，不是剩余额度、费用或当前上下文占用。无记录时留空，选中会话的操作按钮排在下一行。
- 会话数字使用 `/api/usage/session-totals`，只传 Session ID、累计 Token、运行数和窗口信息；服务端短时缓存并合并并发读取，避免每个用户反复下载完整的账单摘要。数据受账本覆盖与十年查询窗口限制。

额度和 Token 数值对所有已登录用户可见，与当前实例共享 Session 的访问边界一致。推广到其他主题时，再决定是否提供独立的「显示用量」开关，并检查各主题与手机端的排版；本次不改变其他主题。
