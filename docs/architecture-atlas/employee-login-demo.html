看身份、会话与网站登记分别存什么
公司身份服务
核验员工身份、维护公司主会话及退出状态；业务网站不持有飞书密码。
RemoteLab 人员记录
按身份服务和用户 ID 对应到 Person；创建人仍为负责人，管理员字段预留。
共享员工会话
同一托管网站入口下复用网关 Cookie。跨应用通过公司 SSO 主会话获得各自凭据；期限由公司策略决定。
新网站登记
配置完成后，网站沿统一托管入口创建，继承员工登录，无需逐站创建账号或 OAuth 应用。

同一浏览器可复用公司主会话；飞书内置浏览器与外部浏览器可能互不共享。旧站独立密码尚未自动迁移。托管网站先接入，RemoteLab 控制台以后单独接入；公司员工或公司管理员身份目前均不授予控制台权限。
