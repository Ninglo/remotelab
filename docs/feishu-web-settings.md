# 飞书 Web 设置接入

话题运行状态、标题摘要与普通插件版本／更新维护见 [话题状态同步](feishu-web-topics.md)。状态连接使用独立只读权限，既有消息设置连接不自动扩权。

可将下面这段交给维护插件和实例的 Agent：

```text
请把飞书 Web 插件的设置整理为「页面显示／消息设置」。保留既有显示偏好、
原生消息、输入草稿和并行维护的模块。消息设置复用当前 Person 的回复配置，
包含首条回复、验收清单、进展展示、开工严格检查和多项工作并行；模型只影响当前
已关联飞书对话的后续消息。保存全部成功后收起，失败时保留草案并说明已保存
的部分。用隔离账号验证读写、账号切换和并发冲突，再核对部署与安装版本。
不要传输实例所有者凭据或代用户完成首次个人账号连接。
```

插件里的页面显示仍按原生飞书账号保存于当前浏览器；布局和宠物位置属于设备。
消息设置直接读写 `person-message-replies.mjs` 的同一份个人配置，因此网页、飞书
私聊、普通群和话题中的后续新工作沿用同一选择。多项工作并行仍受现有群试点限制。
模型修改复用 Session 的运行配置，正在执行的 Run 保留已接纳的模型快照；共享
群话题后续参与者也会使用这个对话的配置，Quick 对话保持创建后固定。

开工严格检查复用已有开关，不新增实验设置页。开启时，既有未标版本的个人配置
绑定规则 v1；请求接入层只为身份匹配且开启的发起人读取独立规则，并记录版本、
正文和来源快照。个人档案保存选择与例外，不复制流程全文。关闭和换人不会清除
模型已见历史，也不改写已接受工作的快照；加载与接续边界见
[个人开工检查](session-work-awareness.md#个人试用开工严格检查)。

首次使用从飞书「设置 → 消息设置 → 连接我的设置」打开独立账号连接窗口，
登录并核对自己的姓名后连接。此窗口不进入完整工作台。连接本身不激活或改变
回复设置。服务器只记录权限有限的随机凭据的哈希，凭据绑定实例、来源和当前
浏览器账号，30 天有效；可在原入口断开连接。原生浏览器账号只用于本地隔离，
不会被当成 RemoteLab Person 的认证证据；Person 来自本人的登录会话。

接入协议仅提供下列能力，不接受所有者／服务凭据，也不赋予文件或任务 API 权限：

- 认证连接页：`GET /page/feishu-web-settings/connect?origin=…&account=…&state=…`。
- 本人登录页签授权：`POST /api/feishu-web-settings/grant`，明确 `confirm: true`。
- 限定凭据：`GET/POST /api/feishu-web-settings/replies`，沿用个人回复的版本校验。
- `GET/POST /api/feishu-web-settings/runtime`，仅接受已关联的飞书 Session、目录中
  可选模型和其支持的思考程度。模型写入在元数据锁内检查版本，拒绝覆盖并发修改。
- `DELETE /api/feishu-web-settings/connection`：撤销当前连接。

请求以 `Authorization: Bearer fwset_…`、`X-Feishu-Origin`、`X-Feishu-Account`
标识连接；凭据不能用于普通实例 API。浏览器扩展通过限定目标和路径的后台
请求器访问接口；当前 Mac mini 联调助手注入的版本使用同一协议直接请求。
两个保存对象分别校验、分别写入；前一项成功而后一项失败时如实显示部分结果，
保持面板打开。未关联工作的话题禁用模型设置，个人消息设置仍可使用。

代码、隔离测试、服务部署、插件安装和本人真实使用分别验收。不要以连接记录、
模拟账号或已部署接口声称本人已经保存或完成飞书使用验收。

## Mac 本地增强试验的账号连接

现有独立 `Feishu Native Trial.app` 可复用 Web 1.2 组件；构建、安装和验收入口见
`scripts/feishu-native/`。既有 Mini 支持飞书 8.0.3 独立试验副本；独立安装器支持 M 系列、飞书 8.1.17 的已核内部构建，不能给正式 App
直接覆盖资源，不能视作支持任意飞书版本的通用安装包。

本机助手固定监听 `127.0.0.1:19342`。服务端仅额外接受精确来源
`http://127.0.0.1:19342`，不接受 `null`、其他端口、`localhost` 或局域网来源。
连接仍由本人在已登录的 RemoteLab 页面核对姓名并点击确认，票据继续按来源、
原生飞书账号和用途分别绑定。原生账号来自客户端本身的账号接口；不得复制网页
票据或借用实例所有者身份。浏览器回传页使用一次性随机状态，10 分钟失效；
本机 API 另需私有能力令牌，固定代理消息设置、个人工作区与只读话题同步操作。

当前导航复用 Web 组件并挂载在原生消息列表内部，最外层官方导航保留。源码构建
固定记录 Web 发布版本及 SHA-256，安装检查试验资源基线、保留原包备份、重新签名
并验证；新版本适配需要重新验证，不能直接套用浏览器扩展的自动更新器。

The same personal parallel-work preference is also available from eligible Feishu group configuration cards. “为我开启试用 / 为我关闭试用 / 查看我的状态” resolve the signed callback operator to their own Person; they do not change group participation, other members, or already accepted inputs. Callback audit entries retain event/chat/message provenance, and repeated callback events cannot undo a later personal choice. See [the scoped trial contract](session-work-awareness.md#personal-trial-controls-on-feishu-group-cards).

## 飞书私聊个人设置卡（2026-10-16，小范围试用）

个人设置以普通飞书私聊为主入口，网页只作备用，沿用同一份 Person 配置。
增强版最终只保留本机显示、连接和当前对话模型等自身功能，不重复放个人
开场、交付清单、进展、并行、记忆开关。当前先验证私聊卡，既有增强版安装
尚未移除旧入口；在卡片验证并覆盖对应使用者之前不让他们失去原设置渠道。

连接器配置 `personalSettings: {enabled: true, webUrl: "https://instance.example"}`
向该连接器访问策略允许的私聊用户开放“我的设置”和“使用说明”入口。
未设 `enabled: true` 时，沿用 `openIds: ["ou_..."]` 限定试用人；默认空名单不触达其他人。
全量开放只改变入口范围，仍按本次操作者解析本人身份，不改变已有人的选择，
不自动开启个人对话记忆，也不扩大个人记忆试点和并行试点群范围。webUrl 只接受无凭据、无查询参数
的 HTTPS 根入口；卡片追加 `?tab=settings`，不会携带所有者或个人登录票据。
网页版需要本人独立登录，不能把飞书身份当作网页登录；链接仅放在明确说明登录要求
的折叠备用区。尚未验证本人能登录的试点应省略 webUrl，使用卡片刷新或私聊
“我的设置”恢复，不将未经验证的网页入口宣传为可用兜底。

已开放的用户在私聊发送“我的设置”“个人设置”或 `/settings`，会在聊天底部重新收到卡片；“使用说明”会展开指南。首次进入私聊通过 `im.chat.access_event.bot_p2p_chat_entered_v1` 发送欢迎卡，首次普通消息仍作补充入口，两者共用持久去重记录。首次进入可沿既有外部身份解析创建本人身份，不启动模型工作、不改个人开关。卡片首屏保留简短个人引入，“个人设置”默认展开，以两列呈现七项设置：进展与清单、记忆与开场、并行与开工核对，以及默认关闭的交付前自检。每项使用浅灰底、统一内边距，名称加粗、简短作用用辅助字号灰字，并保留带边框的下拉选择器；窄屏自动堆叠。选择器展示当前值，修改后自动保存。较长的用途、限制和选择效果保留在设置区域内的“设置详解 · 用途与生效范围”；使用指南按主题逐层展开，并以箭头标明折叠入口。说明覆盖交办、补充、
停止、资料授权、增强安装和可见范围。
个人记忆仍受原试点名单限制；个人并行开关不扩大已登记群范围。

卡片回调校验签名入口后的操作者、租户、原私聊、当前消息和已绑定 Person，
不信任载荷中的身份。下拉回调读取单选 option，布尔值仅接受 true/false，进展值仅接受已列举选项；原按钮回调仍兼容。每次设置沿原版本校验写入，成功后返回当前卡和保存提示；
旧版本冲突只刷新并提示，不覆盖新选择。个人回复的原事件审计防重放；个人记忆
使用明确目标值和版本，不做无条件反转。卡片创建先记发送中状态，无法确认的
网络结果保留该状态，禁止盲目新发；运营核对真实消息回执后恢复原记录。

主动打开始终新发卡片，同一入站消息重放不会重复发送；运营原位更新仍保留 13 天窗口，旧卡不再接受修改。
暂不声称已自动置顶或安装私聊标签页；这些入口需要分别验证实际客户端效果。
说明不会把管理员审批、个人 OAuth、资源访问权或设备权限包装成“一键全授权”。

实现：`connectors/feishu/personal-settings-card.mjs`；入口与长连接回调在
`scripts/feishu-connector.mjs`。

实例可在已核对归属的单张卡记录中加入 `capabilityGuide`（`version: 1`、`intro`、
`sections[{title, body}]`），用于定向试阅能力介绍。章节放入“使用说明”大区域，原有基础设置
及其本人身份校验保持不变；修改设置或刷新后仍保留介绍。示例任务需注明实际归属，
链接沿用原资源权限，展示介绍不启动业务操作，也不自动推断或保存人员方向。
这只是内容试用入口，实际交办仍通过聊天进行。

验证使用隔离环境的 `tests/test-feishu-personal-settings-card.mjs`，覆盖身份隔离、版本冲突、事件重放、
记忆开关、首次欢迎去重及未知发送结果。真实私聊送达和本人点击应分别验收。

说明与基础设置在同一张卡内呈现，两个大区域使用独立且刷新时稳定的组件标识，设置区域默认展开，单项说明与当前值直接可见，选项通过原生下拉框展开；说明区域默认收起。明确要求重发完整试用卡时，发布器可使用 `renew: true` 更新有效消息绑定；保留当前持有人的设置与能力说明，旧卡不能继续修改设置。能力示例人物不改变卡片操作人的身份。

机器人原生悬浮菜单可通过官方 v7 application ability 配置两个 `menu_content_type: 4` 的发送消息入口：“我的设置”和“使用说明”，复用消息处理通路；首次进入需增量订阅上述事件，保留其他事件与长连接方式。能力更改须发布并回读在线版本。菜单可见范围与连接器入口开放范围分开配置；向所有获准私聊用户推全时需显式设置 `personalSettings.enabled: true`，仅发布菜单不会改变后端开放范围。新用户未明确开启时对话个人记忆默认关闭，已有人的选择不变。

并行开关现独立保存为 `parallelWork`。旧共用开关只读兼容为并行选择，新的自动分流固定关闭，旧卡回调不会重新开启它。关闭并行不停止已存在计划。实际实例部署与个人开启另行核验。

## 可选交付前自检

可直接交办：“为我开启／关闭交付前自检，保留其他设置。”也可在私聊“我的设置”卡的“交付前自检”中选择，或登录网页“设置 → 消息”勾选后保存。默认关闭，升级不会替任何现有用户开启。旧卡点击“刷新设置”即可显示新选项，无需安装增强版。

该选择只属于当前实例中已核验的本人，在网页、飞书私聊、群和话题共用。保存后，新工作采用新设置；正在执行的工作、同一人的中途补充和重复请求保留接纳时的快照。运行结束后的新输入才采用新设置。其他参与者按自己的配置取快照，不继承前一人的开启状态。关闭不取消基本诚实和必要验证。

开启后，当前 Harness 在最终交付前对照交办提炼的验收条件，检查完成声明、实际内容和用户可使用的链接或附件，修复已授权范围的缺项并重验。无需用户先填写验收表，也不会每次额外发送自检报告。检查可能增加工具调用、模型用量和交付时间；不增加独立审查模型、后台续跑或重复投递。已有附件交付可以满足验收，发送前不会宣称已经取得尚未产生的回执。

实现与验证边界见[交付前自检执行约定](session-work-awareness.md#可选交付前自检)。

群内的现有“群设置”卡也有独立开关，默认关闭，作用于同一 Bot 和租户的本群主线与话题。本人或本群任一开启就适用，不叠加执行；关闭个人选择不会覆盖已开启的群。设置在后续新工作接纳时生效，运行中的普通补充、排队及重试保留原选择。群卡操作沿现有身份、卡片版本和修改权限校验，不开放新的管理权限。
