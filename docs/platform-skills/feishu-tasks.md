# 待办统一使用飞书任务

人在对话里提出记待办、分配负责人或设置截止日期时，使用已有飞书任务能力。先按 `feishu-cli.md` 选择当前实例已有的 profile 和 Bot/User 身份，再读已安装的 `lark-task` Skill。复用已有任务，创建或更新后读回标题、负责人、截止时间和任务链接；将来源 Session 放入描述。任务登记不代表业务完成。

RemoteLab 自建个人待办已于 2026-10-15 退役：Amber 的 To do 面板、副屏待办来源、个人工作页的本地待办来源和写入接口均移除。`remotelab todo` 只返回退役说明，旧 HTTP 接口返回 `410 personal_todo_retired`，不会继续读写旧清单。执行进度清单、Session 工作记录及 Trigger/Schedule 继续由各自原机制维护。

已有 `display-todos.json` 保留作历史原件，不再是运行中的任务来源。实施退役时先备份原件，逐条核对未完成记录的飞书对应项；已有飞书任务只引用原项，缺项保留原负责人、原截止时间和来源补建。已完成记录归档，不重新创建未完成任务。记录旧 ID 与飞书 GUID 的对应和读回证据，不以删除数据代替清理入口。
