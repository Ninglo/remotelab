# 单人 Skill 提炼试点

可向 Agent 交办：“只为我开启 Skill 提炼试用，不显示公共设置入口。复用原生提问，在出现有依据的候选时问我；确认后制作、验证并交我试用，几天后再决定是否推广。”

这是按当前已核发言人启用的本地试点，不是公共功能开关，也不增加后台扫描或模型。配置在实例 CONFIG_DIR/skill-extraction-trial.json，version=1、revision 为正整数、personId 为唯一试点成员、enabled 为布尔值，source 留实际授权。workspace/catalog/creator 为实例可读绝对路径；不在公共仓库写人员或业务原文。开关由已授权 Agent 维护，本人要求关闭时将 enabled 改 false 并递增 revision，保留草稿与历史，不自动撤销此前单独批准的业务行动。

turn-context-hook 仅给匹配的真实人工输入加入短触发和 [制作方法](skill-extraction-trial/SKILL.md) 指针，规则沿现有快照和压缩恢复路径保存。其他人、自动化和 bot 不启用；关闭后发出本人的关闭说明，旧模型历史不会因此物理消失。制作方法在提出候选前才读取，评分细节在确认后才读取。无前端设置、无定时提炼、无新的确认卡片 API。

确认复用 Harness 原生问题及其本人回答、原话题接续；Harness 负责判断候选版本、实际回答与授权含义，现有传输负责问题回执。异步工具可用时原任务继续；仅有阻塞工具时在原任务合适位置提问。普通个人 SSH CLI 必须另装本人工作区指针并核对实际交互，不能把 RemoteLab 的开关视为全机 CLI 配置。

候选和草稿留在本人的试点 workspace，不进入公共目录。是否有效要依真实新任务对照与几天试用，隔离传输测试和格式验证不能冒充业务增益。正式推广需要本人的后续决定。
