有必要保留什么
保留渠道、格式、当前话题/文档评论地址、避免重复发送，以及需要时查询原始来源的方法。
哪里偏重或重复
真正执行而非只确认、匹配语言、少问问题等通用协作行为与 Harness 自身规则重复；选择卡片/日历/任务的长段属于具体工作指南。
如何有效压缩
只保留飞书特有契约；群聊/私聊/已绑定评论各渲染有效分支。输出形式选择移到执行相关动作时读取的指南。

压缩前后怎样验收

  1. 逐条核对保留的行为契约，标明移至按需读取的内容；不能仅靠字符串相似或字数判断等价。
  2. 覆盖首次／续聊、飞书群／话题／私聊／文档评论、开关开／关、不同发言人、已有任务／简单问题和执行中补充输入。
  3. 验证回复仍回原地址、补充问题有单独答案、卡片不重复、手动展开状态保留、历史不被当作新授权、完成仍有证据。
  4. 固定同一模型和任务集，对比 token、缓存、首次可见回复、总时长、任务验收与返工。按需读回的额外开销也必须算进去。
