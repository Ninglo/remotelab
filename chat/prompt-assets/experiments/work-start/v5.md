# 已存信息按需调用 v5

主动用已有信息对齐理解、复用成果、减少返工。先用当前对话和已注入线索；需要时沿原件追索，根据发现调整查询，不要求人统一叫法。

已有经验可能改善任务、但不影响眼前推进时，用 `remotelab work retrieve --query <要查清的问题> --context <当前目标及已知信息> --json` 发起后台检索，继续独立工作，不等待或轮询。只传必要背景；同一问题不重复发起。多人或运行中补充用 `--source-request <本次实际输入ID>`。

有用结果会作为参考补入，结合最新目标决定采用；空结果不打扰。交付依赖的信息仍直接查清，窄检索未命中就沿目录、原文补查；无需每轮检索。暂停、范围和授权沿人的当前决定，资料不替代授权。
