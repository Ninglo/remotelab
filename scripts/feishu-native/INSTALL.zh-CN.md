# 飞书原生增强：独立 Mac 试装

这份试装包面向 **M 系列 Mac、飞书 8.1.17**，包含第 9 版增强界面。
它会从你已经安装的飞书创建独立副本，需要在副本里重新登录自己的账号。
正式飞书、原登录数据和系统安全设置不变。

**先说明试用范围：** 主题、字体、设置和四个侧栏入口可试；个人 Index、thinking、消息设置需要本人连接 RemoteLab 后验证。群看板、Session 状态、用量和消息成果仍依赖另行配置的状态来源，**这份独立包不包含 Mac mini 的来源连接，也不会因为安装完成而自动接通**。语音输入和会议媒体尚未验收。

## 1. 准备

- 从飞书菜单“关于飞书”确认是 8.1.17。安装器还会检查内部构建；不同版本会停止，不要为试装降级正式飞书。
- 飞书通常位于 `/Applications/Lark.app`。通过 Homebrew 安装的文件可能叫 `Feishu.app`，见下面的终端方式。
- 安装 [Node.js 官方 LTS 版](https://nodejs.org/en/download)，选 macOS 安装包。新安装选择 Node.js 22 或更新的 LTS；已有 Node.js 20 也可运行。安装器会查找通常的安装位置。
- 在终端运行一次 `xcode-select --install`，按 macOS 提示安装 Apple 命令行工具。已有工具会提示已经安装。
- 预留至少 8 GB 空间。解压试装 zip，保留整个文件夹。

## 2. 安装

双击包内 **“安装飞书增强版.command”**。终端会显示检查、复制与签名进度；看到“安装完成”后再关闭。

如果系统拦截这个未公证的内部试装脚本，可按 [Apple 的单个应用放行说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)，在“系统设置 → 隐私与安全性”中对这个文件选择“仍要打开”。无需关闭系统保护。

也可以在终端执行：先输入 `cd `，把解压后的文件夹拖进去，回车，再运行：

```sh
/usr/bin/python3 install-preview.py
```

如果飞书文件名是 `Feishu.app`：

```sh
/usr/bin/python3 install-preview.py --source /Applications/Feishu.app
```

仅检查条件、暂不安装：

```sh
/usr/bin/python3 install-preview.py --check
```

失败时保留终端最后的报错，发回原话题。不要删版本检查、改补丁或反复覆盖安装。检查阶段的版本、签名或依赖失败不会修改应用。

## 3. 打开与连接

1. 双击桌面 **“飞书增强版”**。以后固定用这个入口，也可把用户“应用程序”文件夹里的同名入口拖到 Dock。
2. 在独立试验版中登录自己的飞书账号。它不会复制正式飞书或 Mac mini 的登录数据。
3. 打开增强设置，试一下主题预览、取消恢复和保存；重新打开窗口检查保存结果。
4. 需要个人功能时，在 Index 点“连接本人账号”，并在消息设置里完成对应连接。浏览器页面会要求登录 RemoteLab、核对姓名；完成后返回飞书。不要连接别人的账号。
5. 新机器没有状态来源时会显示“未同步”；这是当前试装包的已知限制，不表示飞书登录失败。请反馈安装结果后再验收独立机器的同步接入。

## 更新与回退

这是首次试装包，**不是自动更新器**；重复安装会拒绝覆盖已有副本。现有 Mac 联调环境的状态数据是实时更新的，但增强代码目前不支持热更新，仍需经过检查后安装并重启独立副本。

想先停用，退出“飞书原生增强试验”，重新打开原来的正式飞书即可。不要在会议或编辑未保存内容时退出。

彻底移除时，先保存试验版中的草稿并退出它，再在 Finder 中将以下项目移入废纸篓（不要动 `LarkShell`）：

- `~/Desktop/飞书增强版.app`：桌面入口。
- `~/Applications/飞书增强版.app`：启动入口。
- `~/Library/Application Support/RemoteLab/Feishu Native Trial`：独立应用、增强配置和日志。
- `~/Library/Application Support/RlfeTrial`：独立试验版的登录及本地数据。移除它会清除试验版登录和本地草稿；需要保留时先留在原处。

安装过程只使用包内程序与本机飞书，不包含他人的账号凭据。首次部署仍需你在自己的 Mac 上确认真实登录后的效果；安装、签名校验不能代替日常功能和会议验证。
